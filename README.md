# Dictation Daily user guide

An illustrated guide to [Dictation Daily](https://dictationdaily.com), published with GitHub Pages:
**https://dictationdaily.github.io/**

One static page (`index.html`) styled with Tailwind CSS, with screenshots of the real app in `images/`.

## Develop

```bash
npm install
npm run dev            # rebuilds assets/site.css on change
python3 -m http.server # then open http://localhost:8000
```

Pushing to `main` builds the CSS and deploys the site (`.github/workflows/pages.yml`).

## Screenshots

Signed-out screenshots come from production, taken by `scripts/capture.py` with Playwright and Chrome. It never signs in, so it saves nothing:

```bash
pip install playwright pillow
python3 scripts/capture.py images            # or: --only library lesson-hint
python3 scripts/to_webp.py
```

The signed-in shots (`account-menu`, `signed-in-library`, `my-learning*`, `lesson-resumed`), plus `lesson-finished`, `lesson-listen`, `lesson-no-transcript`, `not-found` and the hand-captured `google-signin`, come from the app repo's `docs/user/images/` (generated by `tests/e2e/docs_screenshots.py` with the *Demo Learner* account). Never use screenshots that show a real learner's name, email or avatar.
